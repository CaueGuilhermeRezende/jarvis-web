# JARVIS (web)

Build compilado do JARVIS, assistente pessoal privado, publicado pelo GitHub Pages
para ser instalado na Tela de Início do iPhone (Safari → Compartilhar → "Adicionar à Tela de Início").

- Este repositório contém **apenas o app compilado**. O código-fonte é privado.
- **Nenhum dado pessoal fica aqui.** Agenda e demais dados ficam somente no aparelho (SQLite local do navegador).
- Sem servidor, sem telemetria, sem chaves de API.
